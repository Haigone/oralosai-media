# ORA LO SAI - calendario di pubblicazione automatica
- schedule.json: per ogni data (ora italiana) e slot (1=08:00, 2=13:00, 3=20:30) la cartella del post.
- published.json: post gia pubblicati (evita doppioni). La routine lo aggiorna dopo ogni pubblicazione.
- posts/DATA/sN/slide1..8.jpg + caption.txt: contenuti.
